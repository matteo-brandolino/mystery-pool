What to expect

  1. The lab opens in a new tab. For a few seconds it may stay blank, or show the launch address while PortSwigger starts the lab. That address contains the topic id, so look away from the address bar if you want the surprise.
  2. If you're not logged in to PortSwigger, the lab tab goes to the login page first. Log in and you land on the lab.
  3. If your browser blocks the new tab, use the button above.

What this can't do

  • It rolls a topic, not a lab — PortSwigger picks the actual lab inside that category, so the same lab can come up twice.
  • The roll is uniform across topics, not across labs: a category with 3 labs is as likely as one with 12.
  • It can't know which labs you've already completed. That lives behind an HttpOnly cookie on PortSwigger's origin, which no other site can read.
